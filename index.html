Download Frame

Organize your photos on your computer. Frame suggests groups and helps you review similar shots before you decide what to keep.

These preview downloads require a GitHub account with access to the private Frame repository. Each download is a ZIP containing the installer.

Windows

For x64 PCs. Includes People and Screenshots grouping, face matching, and similar-shot recommendations.

Download Windows preview

Extract the ZIP and open Frame-Windows-x64-Setup.exe. Then open Frame Preview from the Start menu. This preview installer is unsigned.

macOS

For Apple Silicon Macs running macOS 14 or later.

Download Mac preview

Extract the ZIP and open Frame-macOS-Apple-Silicon.pkg. Then open Frame Preview from Applications. This preview installer is not notarized.
